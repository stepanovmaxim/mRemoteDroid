# mRemoteDroid

Менеджер подключений RDP, SSH и VNC для Android в духе [mRemoteNG](https://github.com/mRemoteNG/mRemoteNG): **встроенный RDP-движок FreeRDP, свой SSH-терминал и VNC-клиент** — сеанс открывается прямо в приложении, без сторонних клиентов.

## Возможности (1.7.0)

- 📁 **Файлы по SFTP**: просмотр папок на сервере, скачивание, загрузка (с подтверждением замены), новая папка, переименование, удаление; прогресс и отмена передачи; работает и через jump-хост. Пункт «Файлы (SFTP)» в меню SSH-подключения.
- ⚡ **Сниппеты**: сохранённые команды (меню → «Сниппеты» или кнопка ⚡ в терминале), отправляются в терминал одним нажатием, с Enter или без.
- 🔑 **Генерация SSH-ключей** в приложении: Ed25519, ECDSA P-256, RSA 3072; публичный ключ можно скопировать или отправить, у сохранённого ключа — показать.
- 🔐 **SSH-туннели**: любое подключение RDP, VNC или SSH можно провести через SSH-сервер из списка (jump-хост / бастион); туннель открывается при подключении и закрывается вместе с сеансом, при обрыве переподключается сам. Поле SSHTunnelConnectionName из confCons.xml mRemoteNG импортируется и экспортируется.
- 🔀 **Проброс портов в SSH**: `L 8080:intranet:80`, `R 9000:localhost:22`, `D 1080` (SOCKS 4/4a/5); локальные порты слушают только 127.0.0.1.
- 🟢 **Доступность серверов**: точка у подключения показывает, отвечает ли порт (для туннеля — SSH-сервер, для RD Gateway — шлюз); отключается в меню.
- ⏻ **Wake-on-LAN**: MAC-адрес в подключении (импортируется из mRemoteNG), «Включить» в меню подключения.
- 💻 **SSH**: терминал (xterm-256color, цвета, копирование и вставка, масштаб щипком), панель клавиш Esc/Tab/Ctrl/Alt/стрелки/F1–F12, вход по паролю, keyboard-interactive или ключу (OpenSSH/PEM: ed25519, ECDSA, RSA, в том числе с парольной фразой), проверка ключа сервера (запоминается, смена ключа — предупреждение).
- 🖼️ **VNC**: свой RFB-клиент (3.3–3.8), пароль VNC, VeNCrypt с TLS (X509None/Vnc/Plain), Apple Remote Desktop; кодировки ZRLE, Hextile, RRE, CopyRect, Raw; тап — клик, долгий тап — перетаскивание, два пальца — прокрутка / тап двумя пальцами — правый клик, щипок — масштаб; Ctrl+Alt+Del, Win, F1–F12, отправка буфера обмена на сервер.

- 🖥️ **Встроенный RDP** (FreeRDP 3.11 + OpenSSL): полноэкранный сеанс, альбомное разрешение по размеру экрана, «вписать в экран» в портрете, pinch-zoom.
- ✋ **Управление касаниями**: тап — клик, двойной тап — двойной клик, долгий тап — перетаскивание, два пальца — прокрутка / правый клик; режим курсора мыши.
- ⌨️ **Клавиатура**: Unicode-ввод (кириллица и латиница независимо от раскладки на сервере), Backspace/Enter, панель Esc/Shift/Ctrl/Win/Alt и функциональные клавиши; долгое нажатие на плавающую кнопку — показать/скрыть клавиатуру.
- 🔘 **Плавающее меню сеанса** (перетаскиваемое): курсор мыши, клавиатура, F-клавиши, поворот, вписать в экран, к списку подключений, отключиться.
- 🗔 **Несколько сеансов одновременно** (до 5): каждый сеанс — отдельное окно и карточка в «Недавних». Переключение — через «Недавние», список подключений (открытые отмечены зелёным, тап возвращает в сеанс без переподключения) или уведомление. Свёрнутым сеансам сервер не шлёт картинку (Suppress Output) — экономия трафика и батареи. Смахнуть карточку = закрыть сеанс.
- 🖥️ **Динамическое разрешение** (как в mstsc): при изменении окна — Samsung DeX, разделённый экран, поворот — сервер меняет разрешение рабочего стола под размер окна (канал Display Control, Windows 8.1 / Server 2012 R2 и новее; на старых серверах картинка просто масштабируется).
- 🔍 **Масштаб рабочего стола**: авто по плотности экрана (Fold, планшеты) или вручную 100–250% в меню сеанса и в главном меню, применяется на лету (Windows 8.1 / Server 2012 R2 и новее).
- 🔄 **Свой автоповорот сеанса**: «Поворот: авто / альбомный / портретный»; режим «авто» работает по датчику даже при выключенном системном автоповороте, выбор запоминается.
- 🏛️ **Старые серверы**: Windows Server 2008 / 2008 R2 (TLS 1.0, сертификаты SHA1, RDP Security с RC4); новые серверы по-прежнему используют TLS 1.2/1.3 и NLA.
- 🔋 **Сеансы не рвутся при выключенном экране**: foreground-сервис с уведомлением «Подключено: хост» / «Открыто сеансов: N».
- 🗂️ **Дерево папок и подключений**, поиск и сортировка.
- 🔐 **Пароли** шифруются AES-256/GCM ключом из Android Keystore; опционально — биометрическая разблокировка.
- 🌐 **7 языков интерфейса** по языку системы: английский, русский, немецкий, испанский, французский, итальянский, китайский (на Android 13+ язык можно выбрать отдельно для приложения).
- ℹ️ **«О приложении»**: версия, ссылки на исходный код и политику конфиденциальности, лицензии открытого ПО.
- 🔑 **Сохранённые логины**: один логин и пароль для многих серверов или для целой папки, меняются в одном месте.
- 📌 **Ярлыки** подключений на рабочем столе, недавние подключения в списке и в меню значка приложения.
- 🌉 **RD Gateway** с отдельным логином шлюза.
- 🔊 **Звук**: на устройстве, на сервере или выключен (для каждого подключения).
- 📁 **Общая папка**: сервер видит папку приложения «mRemoteDroid» как диск; на телефоне она открывается через меню или приложение «Файлы». Разрешение на доступ ко всем файлам не требуется.
- 📄 **Импорт `.rdp`, RDCMan `.rdg` и CSV** (колонка хоста обязательна), файлы `.rdp` открываются из других приложений. Пароли из `.rdp` и `.rdg` защищены Windows (DPAPI) и не переносятся; проброс дисков из файлов не применяется.
- 📥📤 **Импорт и экспорт `confCons.xml`** mRemoteNG (≥1.76, AES-GCM/PBKDF2; дефолтный пароль файла `mR3m`) с расшифровкой/шифрованием паролей.

## Стек

- Kotlin + Jetpack Compose (Material 3), Room, Navigation Compose, androidx.biometric
- SSH: [JSch](https://github.com/mwiede/jsch) + Bouncy Castle (Ed25519/X25519 на всех версиях Android), терминал Termux
- Модуль `:freeRDPCore` — Android-клиент FreeRDP (JNI + экран сеанса), доработан: immersive fullscreen, клавиатура/IME, касания, keep-alive
- `minSdk 26`, `targetSdk 36`, ABI: `arm64-v8a`, `x86_64`

## Структура

```
app/                         приложение (дерево подключений, импорт/экспорт, настройки)
  launch/EmbeddedRdpLauncher.kt   запуск сеанса (RDP: freerdp:// → SessionActivity; SSH/VNC: свои окна)
  remote/ssh/                SSH (JSch + терминал), проверка ключей серверов
  remote/vnc/                VNC: RFB-клиент и экран
terminal/                    терминал Termux (terminal-emulator + terminal-view, Apache 2.0), pty заменён на транспорт SSH
freeRDPCore/                 FreeRDP Android client
  src/main/cpp/              JNI-мост (собирается локально через NDK)
  src/main/jniLibs/<abi>/    предсобранные libfreerdp3/winpr3/freerdp-client3/ssl/crypto/cjson + include/
.github/workflows/build-freerdp.yml   сборка нативных библиотек FreeRDP на Linux (Release)
```

## Сборка

Нужны Android Studio (JBR 17+), Android SDK 36, NDK `27.2.12479018`, CMake `3.22.1`.

```bash
./gradlew assembleRelease
```

Готовые APK — по одному на ABI (`app-arm64-v8a-release.apk` для телефонов) и универсальный.

Для Google Play — app bundle: `./gradlew bundleRelease` → `app-release.aab` (разбиение по ABI в этом случае отключается автоматически).

**Подпись release**: локальный `keystore.properties` (в git не попадает):

```properties
storeFile=keystore/release.jks
storePassword=...
keyAlias=mremotedroid
keyPassword=...
```

Без него release собирается неподписанным. Подпись v2 + v3.

**Нативные библиотеки FreeRDP** собираются не на Windows, а в GitHub Actions: запустить workflow *Build FreeRDP Android libs*, скачать артефакт `freerdp-jnilibs` и положить `.so` + `include/` в `freeRDPCore/src/main/jniLibs/<abi>/` (`.so` стоит стрипнуть `llvm-strip --strip-debug`).

## Отладка

Debug-сборка умеет открыть демо-сеанс без сервера (весь UI сеанса, ввод пишется в logcat как `LibFreeRDP: demo ...`):

```bash
adb shell am start -a android.intent.action.VIEW -d freerdp://demo.local -n com.mremotedroid.app/com.freerdp.freerdpcore.presentation.SessionActivity
```

Если подключение не устанавливается, лог FreeRDP можно снять так:

```bash
adb logcat -s FreeRDP:* GlobalApp:* com.freerdp.*:*
```

## История версий

- **1.7.0** — файлы по SFTP, сниппеты, генерация SSH-ключей; окна сеансов переведены на штатный edge-to-edge (рекомендации Google Play для Android 15).
- **1.6.1** — исправлены падение при закрытии RDP-сеанса во время подключения и падение на 32-битных телефонах (теперь приложение ставится только на 64-битные).
- **1.6.0** — SSH-туннели и jump-хосты для RDP/VNC/SSH, проброс портов (L/R/D), индикатор доступности серверов, Wake-on-LAN, запрос оценки в Google Play.
- **1.5.0** — SSH (встроенный терминал, вход по паролю или ключу, проверка ключа сервера) и VNC (свой RFB-клиент, пароль VNC, TLS, Apple Remote Desktop).
- **1.4.0** — импорт `.rdp`, `.rdg` и CSV, сохранённые логины и логин папки, ярлыки и недавние подключения, звук, общая папка, логин шлюза; масштаб рабочего стола по умолчанию в главном меню; исправлено: подключение через RD Gateway (использовался параметр `/g`, отсутствующий в этой сборке FreeRDP), сброс масштаба при возврате в открытый сеанс Windows, самопроизвольное появление клавиатуры при переподключении.
- **1.3.1** — масштаб рабочего стола: на плотных экранах (Fold, планшеты) он больше не мелкий; пункт меню «Масштаб»; на больших экранах рабочий стол следует за окном и в вертикальной ориентации.
- **1.3.0** — динамическое разрешение: рабочий стол подстраивается под размер окна (Samsung DeX, разделённый экран, поворот).
- **1.2.0** — интерфейс на 7 языках, экран «О приложении» с лицензиями, политика конфиденциальности, данные исключены из переноса на другое устройство.
- **1.1.1** — нативные библиотеки собраны с выравниванием 16 КБ (требование Google Play для Android 15+, NDK r28); сервис удержания сеанса стартует сразу при подключении (сеанс защищён, даже если свернуть приложение во время подключения); сборка AAB для Google Play.
- **1.1.0** — несколько сеансов одновременно, пункт меню «К списку подключений», Suppress Output для свёрнутых сеансов; пароль больше не попадает в intent окна сеанса (передаётся в памяти).
- **1.0.3** — подключение к Windows Server 2008 / 2008 R2 (TLS 1.0 и SHA1 разрешены: OpenSSL 3 по умолчанию их отклонял).
- **1.0.2** — автоповорот сеанса внутри приложения, пункт меню «Поворот».
- **1.0.1** — ручное отключение больше не показывает «Соединение прервано».
- **1.0.0** — только встроенный RDP (вызов сторонних клиентов убран), R8, подпись v2+v3, APK по ABI.
