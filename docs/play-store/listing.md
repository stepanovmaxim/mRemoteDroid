## en-US

**Title:** mRemoteDroid – RDP Manager

**Short description:** Remote desktop (RDP) connection manager with folders and a built-in client

**Full description:**

mRemoteDroid is a remote desktop connection manager for administrators who look after many Windows machines. Keep all your RDP servers in a folder tree, connect with one tap and work in several sessions at once, all in a built-in RDP client based on FreeRDP.

FEATURES
• Folder tree of connections, search by name, host or user, sorting
• Built-in RDP client (FreeRDP): no other app needed
• Several sessions at the same time, each in its own window in Recents; open sessions are marked in the list
• Touch control: tap to click, double tap, drag, two-finger scroll and right click, optional mouse pointer
• Keyboard with Unicode input (any language, independent of the server keyboard layout), Esc/Ctrl/Alt/Win and function keys
• Automatic screen rotation inside the session, even when system rotation is locked
• Sessions stay connected with the screen off
• Saved passwords encrypted with a key in the Android Keystore, optional fingerprint/face unlock
• Import and export of confCons.xml files compatible with mRemoteNG, including encrypted passwords
• Network Level Authentication (NLA), TLS, RD Gateway, console session (/admin)
• Connects to Windows and Windows Server computers with Remote Desktop enabled
• No ads, no tracking, no account. Open source.

PRIVACY
All data stays on your device. The app only connects to the servers you add.

mRemoteDroid is an independent open-source project and is not affiliated with the mRemoteNG project. FreeRDP is used under the Apache License 2.0 and the Mozilla Public License 2.0.
